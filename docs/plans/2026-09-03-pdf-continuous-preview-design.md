# PDF 全页连续预览设计

## 背景

当前 `PdfPreview` 只维护一个 Canvas，通过上一页和下一页按钮切换页码。
弹窗内容区固定高度，页面按宽度缩放后经常只能看到一部分，用户无法像以前一样
连续下拉浏览整份档案。

## 目标

- PDF 所有页面按顺序纵向连续显示，可直接滚动阅读。
- 默认使用整页适配，让每张页面完整进入可视区域。
- 提供整页和适宽两种适配模式，保留缩放能力。
- 工具栏显示当前滚动页和总页数，不再要求手动翻页。
- 工程档案和回款发票继续复用同一查看器。
- 保持现有鉴权、同源 Worker、禁止动态求值、错误重试和下载入口不变。

## 方案

### 页面渲染

文档加载完成后为每一页建立稳定的页面占位组件。页面组件根据容器宽度、
可用高度和当前适配模式计算基础比例：

- 整页：同时受可用宽度和可用高度约束，确保整张页面可见。
- 适宽：只按可用宽度计算，适合放大阅读正文。

用户缩放在基础比例上叠加，缩放范围继续保持 75% 到 250%。

### 性能

不在文档打开时一次性绘制全部页面。使用 `IntersectionObserver` 观察页面占位，
只绘制进入视口或接近视口的页面；已经绘制的页面保留 Canvas，避免来回滚动时
反复请求和绘制。观察器不可用时降级为顺序渲染，保证兼容性。

每页拥有独立渲染任务和取消清理逻辑。文档切换、缩放、适配模式变化或组件卸载时，
取消旧任务，防止旧页面覆盖新尺寸。

### 工具栏与交互

- 删除上一页和下一页按钮。
- 显示 `当前页 / 总页数`，当前页由可见面积最大的页面决定。
- 增加整页和适宽切换，默认整页。
- 缩放按钮作用于所有页面。
- 页面之间保留清晰间距和阴影，整体形成连续长页。

### 容器布局

预览弹窗继续限制在浏览器可视区域内，滚动只发生在 PDF 内容区，不带动背景页面。
桌面和手机共用连续布局；手机端减小页面间距和内边距，最大化可用显示面积。

## 错误处理

- 文档加载错误继续显示现有中文提示和重新加载按钮。
- 单页渲染失败时在对应页面位置显示错误提示，其余页面仍可浏览。
- 加密、无效和丢失 PDF 继续使用现有分类提示。

## 验证

- 静态契约测试确认不再出现上一页和下一页，并存在整页、适宽和连续页面列表。
- 覆盖页面比例计算、当前页判定和懒渲染触发的单元测试。
- 运行完整测试、TypeScript、Vite 构建、依赖审计和差异检查。
- 使用多页 PDF 在桌面和 390px 手机视口验证整页、适宽、缩放、连续滚动、
  当前页更新、重试和关闭。

## 非目标

- 不修改 PDF 文件、档案数据、上传接口、权限或下载方式。
- 不恢复浏览器原生 PDF 插件或 iframe。
- 本次没有用户授权部署或 GitHub 发布，完成本地修改与审核后等待后续指令。

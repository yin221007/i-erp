# PDF 全页连续预览实施计划

## 任务 1：锁定布局行为

文件：

- 新增 `lib/pdf-preview-layout.js`
- 新增 `lib/pdf-preview-layout.d.ts`
- 新增 `tests/unit/pdf-preview-layout.test.js`
- 修改 `tests/frontend/api-client.test.js`

步骤：

## 任务 2：实现连续懒渲染

文件：

- 修改 `components/PdfPreview.tsx`

步骤：

1. 将单 Canvas 改为每页独立 Canvas 和稳定占位。
2. 使用 `IntersectionObserver` 只激活视口附近页面。
3. 默认整页适配，增加适宽模式，缩放作用于全部页面。
4. 使用可见比例更新当前页，删除上一页和下一页交互。
5. 保留鉴权、Worker、禁用动态求值、重试和错误分类。
6. 为单页失败提供局部提示，不阻断其他页面。

## 任务 3：定向验证

步骤：

1. 运行布局单元测试和前端契约测试。
2. 运行 TypeScript 和 Vite 生产构建。
3. 修复全部失败，并运行 `git diff --check`。

## 任务 4：浏览器验收

步骤：

1. 准备本地多页 PDF 测试夹具。
2. 在桌面视口确认默认整页、连续下拉、当前页、适宽和缩放。
3. 在 390px 手机视口确认页面完整、连续滚动和工具栏可操作。
4. 检查控制台错误、Worker 请求和 Canvas 数量。

## 任务 5：全面审核

步骤：

1. 运行完整 `npm run verify:release`。
2. 检查依赖审计、生产构建、Bash、Compose、部署脚本和差异。
3. 复核工程档案与发票两个入口均使用同一组件。
4. 更新交接记录，明确本地完成状态及未部署事项。
